# 统一使用 Python 3.10

## 背景

项目仅需支持 Python 3.10，不再需要兼容 Python 3.8 或 3.12。

## 实现

- `requires-python` 限定为 `>=3.10,<3.11`，即仅接受 Python 3.10.x。
- Ruff 目标版本改为 `py310`，mypy 目标版本设为 `3.10`。
- README、架构文档和 Unreleased Changelog 更新版本范围。
- GitHub Actions 工作流已在工作区配置为单独使用 Python 3.10；保留该现有改动。

## 验证

- 使用当前 Python 3.11.5 的 `tomllib` 解析 `pyproject.toml`，确认项目版本限制和工具目标版本。
- 当前解释器不是 3.10，因此未用当前解释器执行受限安装；CI 使用 Python 3.10。

## 涉及文件

- `pyproject.toml`
- `README.md`
- `docs/architecture.md`
- `CHANGELOG.md`
- `.github/workflows/quality.yml`（保留工作区已有的 Python 3.10 单版本配置）
